# Пуш-напоминания и реклама

## Пуш-напоминания (по образцу «Выжить до пятницы»)
- Включает сам игрок: «Профиль» → «Напоминания» → «🔔 Напоминать мне играть», или окно-предложение после пройденной миссии («Позже» — снова через 3 дня, «Не спрашивать» — никогда).
- Только на сайте (https). iPhone — только если игра добавлена на экран «Домой» (иначе показывается подсказка). В мини-приложениях Telegram, ВК и MAX выключено.
- Сервер: функция `nf-push` (ключи VAPID создаёт сама, таблица `nf_push_keys`; подписки — `nf_push_subs`).
- Расписание (pg_cron): 09:40, 13:40, 19:40 по Москве (`nf-push-morning`, `nf-push-day`, `nf-push-evening`). Каждому подписчику 1–3 уведомления в день; кто играл последние 3 часа — не беспокоим.
- Тексты — `supabase/functions/nf-push/texts.ts`: общие (утро, день, вечер, выходные) и личные (бензин, грязь, ремонт, «{водитель} ждёт тебя», сюжет). Только правда об игре.
- Ручная рассылка: POST в `nf-push` с `{ key: <nf_settings.cron_key>, custom: { t, b } }`.

## Реклама Рекламной сети Яндекса
- Блок `R-A-20345213-1`, полноэкранный, для телефона (touch). `ads.txt`: `yandex.com, 20345213, DIRECT`.
- Только на сайте и на телефоне, между миссиями сюжета (со второй пройденной миссии), не чаще раза в 5 минут. Код Яндекса загружается только перед показом.
- В мини-приложениях Telegram, ВК и MAX не показывается (в ВК по правилам — только реклама ВК). Тестовому профилю не показывается.
- Пока сайт не прошёл модерацию в кабинете РСЯ, Яндекс ничего не показывает.
- Политика обработки персональных данных (п. 5.3 и 5.4) обновлена.
