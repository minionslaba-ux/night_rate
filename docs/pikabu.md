# Пикабу Игры

**Статус:** опубликована 13 ноября 2026 (подано 9.11; замечание модерации 12.11 — тормоза на старте, исправлено в v122–v124).

**Основной путь — напрямую через Пикабу** (владелец — самозанятый: 50% чистого дохода против 40% через GamePush).
Игра лежит на нашем сайте: https://nightfaregame.com/pikabu/ (страница `pikabu/index.html`, собирается `tools/build_pikabu.py`; модели и движок — из общих папок сайта через `<base href="/">`; для поисковиков — `noindex`). SDK Пикабу (`https://games.pikabu.ru/sdk/sdk.js`, `PkbSDK`) работает только внутри Пикабу Игр или в тестовом окружении Студии.

## Напрямую: что делает игра (`PK_DIRECT`)
- `PkbSDK.init()` после первого экрана, сразу `sdk.gameStarted()`; реклама перед загрузкой (preloader) не используется — она сильнее всего бьёт по первому впечатлению.
- Облачные сохранения (обязательны): `sdk.storage` ключ `nf` = `{ v, t, p: профиль, pr: прогресс сюжета }`, запись через 3 с после изменения (SDK сам отправляет на сервер). При запуске и после входа игрока в аккаунт Пикабу выигрывает сторона, где игрок продвинулся дальше; посреди миссии — применяется в меню. `REVISION_CONFLICT` (изменено в другой вкладке) — подсказка перезапустить, сохранения останавливаются.
- Реклама за награду: `ads.rewarded.canShow()` → `show()`; награда только при `reward: true`; закрыл раньше — без награды; рекламы нет — награда без неё. Между миссиями: `ads.fullscreen` со 2-й миссии, не чаще раза в 5 минут (у платформы — 2 минуты), только на экране итогов, не во время игры. На время рекламы — пауза и выключенный звук. Журнал — `nf_ads` (`pikabu rewarded` / `pikabu fullscreen`).
- Покупки: наборы магазина через `sdk.store.purchase` → проверка подписи на нашем сервере (`nf-pikabu`, секрет `PIKABU_SECRET`) → выдача; монеты подтверждаются `consumePurchase`; недовыданные покупки — при запуске (`getPurchases`). Товары для Студии — `promo/pikabu/tovary-pikabu.csv`.
- Наш вход, ссылки, Робокасса, реклама сайта, пуш-уведомления, наш облачный профиль, вкладки «Рейтинг» и «Друзья», рейтинг задания дня на Пикабу выключены.

## Напрямую: что сделать владельцу в Студии (games.pikabu.ru/studio)
1. **Настройки → Документы:** данные для выплат (самозанятый). Без них игру не отправить на модерацию.
2. **Игры → Добавить игру:**
   - название: Ночной тариф;
   - ссылка на игру: `https://nightfaregame.com/pikabu/`;
   - устройства: компьютер, телефон, планшет; ориентация: горизонтальная и вертикальная;
   - возрастной рейтинг: 12+;
   - основной жанр: Гонки (дополнительно: Шутер, Машины, Приключения);
   - краткое описание (до 250 знаков), «Об игре», «Как играть» — тексты ниже;
   - иконки: `promo/pikabu/icon-1024x1024.png` и `promo/pikabu/cover-1920x1080.jpg`; скриншоты: `promo/pikabu/screen-1…4-1280x720.jpg`.
3. **Тестирование:** создать тестовое окружение со ссылкой `https://nightfaregame.com/pikabu/` — Студия даст тестовую ссылку (реклама — заглушки, сохранения только локально). Прислать её Claude для проверки.
4. **Отправить на модерацию** (до 3 рабочих дней).

## Запасной путь: GamePush

## Что нужно от владельца
1. Зарегистрироваться на gamepush.com, создать проект игры.
2. Номер проекта и публичный токен записаны в `tools/pikabu.json` (проект 32895; токен публичный, он и так виден в коде игры).
3. В GamePush загрузить архив `dist/nochnoy-tarif-pikabu.zip`, иконки из `promo/pikabu/`, описание (ниже) и отправить на Пикабу Игры.

## Сборка
`python3 tools/build_pikabu.py` → папка `dist/pikabu` и архив `dist/nochnoy-tarif-pikabu.zip` (в git не попадают).
Сборка берёт `index.html` сайта и добавляет `window.NF_PLATFORM = "pikabu"` и `window.NF_GP` (проект GamePush), убирает манифест (без сервис-воркера), canonical и метки соцсетей сайта.

## Режим «Пикабу» в игре (`PIKABU`)
- Нет нашего окна входа: играют как гость, прогресс на устройстве.
- В профиле нет блока входа, кода для других устройств, ссылок на документы сайта, сообществ и упоминаний других площадок; оплаты через Робокассу и рекламы сайта (РСЯ, VK Реклама) нет; пуш-уведомлений нет.
- Реклама — через GamePush: кнопки «за рекламу» (продолжить, удвоить, патроны) — `gp.ads.showRewardedVideo()`, между миссиями (со 2-й, не чаще раза в 5 минут) — `gp.ads.showFullscreen()`. Звук на время рекламы выключается. Журнал — `nf_ads` (`gp reward` / `gp fullscreen`).
- SDK GamePush (`https://gamepush.com/sdk/game-score.js?projectId=…&publicToken=…&callback=nfGPInit`) грузится после первого экрана и запуск не задерживает. Без номера проекта SDK не подключается, награда за рекламу выдаётся сразу.
- Облачные сохранения GamePush (поле `nf`): при запуске выигрывает сторона, где игрок продвинулся дальше (заработано + 100 за миссию); облачное сохранение, пришедшее посреди миссии, применяется в меню. Сохранение — через 3 с после любого изменения профиля или прогресса. Вход на Пикабу GamePush делает сам.
- Реклама с наградой: если ролика нет (нет в наличии, блокировщик) — награда без рекламы; ролик закрыт до конца — без награды.
- Игра сообщает GamePush о начале и конце игрового процесса (`gameplayStart`/`gameplayStop`) и о готовности (`gameStart`). SDK грузится через их же четыре зеркала.
- Ещё не сделано: покупки через GamePush.

## Картинки (`promo/pikabu/`, сняты прямо из игры, без интерфейса)
- `icon-1024x1024.png` — иконка 1024×1024, без текста (погоня, вид сверху).
- `cover-1920x1080.jpg` — обложка 1920×1080 с названием.
- `screen-1…4-1280x720.jpg` — 4 горизонтальных скриншота 1280×720.
Требования GamePush к промо: без обрезанных и скруглённых краёв, чёткие, не на белом фоне, показывают игру; у иконки нет текста; у обложки есть название, нет интерфейса.

## Кабинет GamePush (проект 32895): что заполнить
1. **Игроки → Поля игрока → Добавить поле:** ключ `nf`, тип «строка», по умолчанию пусто. В нём облачное сохранение (весь прогресс одной строкой).
2. **Реклама:** включить «Показывать отсчёт перед полноэкранной рекламой».
3. **Настройки проекта:** устройства — компьютер, телефон, планшет; ориентация — горизонтальная и вертикальная.
4. **Тексты** (ниже): название (до 48 знаков), краткое (до 255), полное (до 1024), «Как играть» (до 1024).
5. **Хостинг игр:** загрузить `dist/nochnoy-tarif-pikabu.zip` (index.html в корне архива). Черновик **не публиковать** — GamePush сам размещает его на площадках.
6. **Промо:** иконка, обложка, 4 скриншота из `promo/pikabu/`.
7. **Дистрибуция:** покупки в игре — нет (пока), площадка — Пикабу Игры, в комментарии — ссылка на сайт игры для проверки, «Отправить на модерацию» (ответ — в течение рабочего дня).

## Тексты для каталога
**Название:** Ночной тариф

**Краткое (≤250):** Ночное такси в 3D-городе: довези кейс через весь Порт-Северный, уйди от погони банды «Шакалы», отстреливайся на ходу и пройди 22 эпизода сюжета.

**Полное (≤1024):** Порт-Северный, без тринадцати три ночи. Ты — водитель ночного такси, и сегодня в твоей машине кейс, за которым охотится банда «Шакалы». Сюжет из 22 эпизодов: погони по ночным улицам, перестрелки, ограбление банка, аэропорт и вокзал, а потом — Париж, Лондон и Нью-Йорк. Десять водителей со своими умениями, гараж с машинами и тюнингом, оружие, звёзды за миссии, задание дня с рейтингом и открытый город с тысячами заданий: гонки по точкам, дрифт, тараны, фотоохота. Играть можно с телефона и с компьютера, прогресс сохраняется.

**Как играть (≤1024):** Компьютер, за рулём: WASD или стрелки — руль и газ, Shift — занос, пробел — огонь (прицел наводится сам), N — нитро, B — щит, V — камера. Пешком: WASD — бег, мышь — обзор, клик — выстрел, Q — аптечка, R — купить патроны. Телефон: джойстик слева — руль или ходьба, кнопки справа — огонь, занос, нитро. Следуй за стрелкой маршрута, выполняй цель миссии, собирай монеты и улучшай машину и героя в профиле. Пауза — Esc.
