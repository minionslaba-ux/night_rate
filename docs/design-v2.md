# Дизайн v2 (из Claude Design)

Источник — архив `design_handoff_night_rate_v2` (сборка игры на основе старой версии: three.js r128, один эпизод).
Целиком файл не подменялся: в нём нет 16 эпизодов, открытого города, входа через мессенджеры и т. д.
Перенесён слой стилей (в конце `<style>`, раздел «design v2»):

- шрифты: Unbounded (заголовки), Onest (интерфейс), JetBrains Mono (цифры);
- токены: `--ink #08090d`, стекло `--glass`/`--glass-2`, обводки `--hair`/`--hair-2`, `--taxi #ffc43d`, `--neon #ff3d6e`, `--ok #6fe3a1`, радиус 4px, срез 10px;
- главная кнопка — жёлтая со срезом двух углов и полоской «шашечек», вторичная — прозрачная с обводкой;
- HUD: стеклянные панели, задание с мигающей точкой, сегментная шкала прочности, спидометр как LED-таксометр «Тариф · Ночной»;
- тосты с плашкой «РАЦИЯ», диалог-рация, итог эпизода — кассовый чек;
- титул, выбор водителя, чипы эпизодов, карточки — в тех же токенах.

Не перенесено:
- 3D-модели людей и машины из архива: лицензии не позволяют выкладывать их на публичный сайт (в README макета они помечены «для релиза заменить», Mixamo нельзя распространять как ассеты), вместе ~46 МБ, и код под старую версию three.js;
- процедурная музыка — можно перенести отдельно.
