# Бот @night_fare_bot

Функция `supabase/functions/nf-bot` (вебхук Telegram), по образцу бота «Выжить до пятницы».

- **Всем:** `/start`, `/play` — кнопка «Играть» (открывает игру как мини-приложение) и ссылка на сайт. Нажавшие `/start` попадают в список подписчиков для рассылки.
- **Владельцу** (Telegram ID в таблице `nf_admins`) — полное меню команд, `/help` показывает всё:
  - статистика: `/stats`, `/yesterday`, `/week`, `/online`, `/new`, `/top`, `/find`, `/player`, `/export` (Excel);
  - чат и модерация: `/chat`, `/hide номер`, `/reports`, `/ban логин`, `/unban логин`;
  - игра: `/tester логин on|off`, `/errors`, `/health`;
  - рассылка: `/broadcast текст` — сначала превью, кнопки «Отправить», «Отмена», «Только мне»;
  - правки: `/idea текст`, `/ideas`. Чтобы идея попала в работу, напишите Claude «посмотри идеи из бота».
- **Подключение** (после изменения команд): открыть `https://xqgibyazilueurdqufso.supabase.co/functions/v1/nf-bot?setup=1`. Ставит вебхук и меню команд. Чужой вебхук не перезаписывается без `&force=1`.
- Запросы Telegram проверяются секретом, выведенным из `TELEGRAM_BOT_TOKEN`. Токен в коде не хранится.
- Добавить второго админа (SQL Editor): `insert into nf_admins (tg_id, name) values (123456789, 'имя');` и снова открыть ссылку `?setup=1`.

## Канал @nightfaregame

Бот — администратор канала. Посты только правдивые: никаких выдуманных акций и розыгрышей.

- **Автопост** каждый день в 19:07 МСК (pg_cron `nf-daily-post`, ключ в `nf_settings.cron_key`, не больше одного поста в день — таблица `nf_posts`). Темы по дням (`posts.ts`): Пн — возможности игры, Вт — водитель недели, Ср и Сб — совет, Чт — место в городе, Пт — пятничная смена, Вс — итоги недели из базы.
- `/autopost on|off` — включить или выключить автопост.
- `/postnow` — показать сегодняшний пост с кнопкой «В канал».
- `/news текст` — своя новость: превью, потом кнопка «В канал».
- `/pin` — опубликовать и закрепить сообщение с быстрым меню (Играть в Telegram, сайт, группа ВК). Повторный `/pin` редактирует уже закреплённое сообщение. Боту нужны права «Публикация», «Редактирование» и «Закрепление сообщений».
