# Арсенал: оружие за монеты

В профиле есть вкладка «Оружие»: 15 стволов, у каждого картинка, шкалы (урон, темп, точность, дальность), особенность, магазин и время перезарядки. Ствол покупают за монеты, и он сразу оказывается в руках. Купленные стволы можно менять кнопкой «Взять».

## Как открываются

Ствол становится доступен после нужного числа пройденных эпизодов (`PROF.st.eps`):

| Сколько эпизодов пройдено | Стволы |
|---|---|
| 0 | Шмель (выдают бесплатно) |
| 1 | Кобра |
| 2 | Шершень, Пчела |
| 3 | Бульдог, Мясник |
| 4 | Тень, Ворон |
| 5 | Вихрь |
| 6 | Таран |
| 7 | Сокол-К |
| 8 | Молот |
| 9 | Полярник |
| 10 | Бетон, Шлагбаум |

Тестовый профиль (`is_tester`) получает всё бесплатно.

## Как стреляет

- **«Шмель»** стреляет как прежний пистолет. Остальные стволы считаются от него:
  - урон × `dmg / 18`;
  - пауза между выстрелами × `320 / rpm`;
  - разброс × `(100 − acc) / 28`;
  - дальность полёта пули × `range / 25`, но не больше прежней.
- **Дробовики** выпускают `pellets` дробин за выстрел, с дополнительным разбросом.
- **Патроны** у всех стволов общие (`PROF.inv.ammo`): один выстрел — один патрон, комплект покупается в магазине.
- **Пешком** работает магазин: после `mag` выстрелов идёт перезарядка `reload` секунд. Чтобы стартовый пистолет за долгий бой наносил столько же урона, сколько раньше, урон пешком умножен на 2,6 / 1,5.
- **Из машины** стреляют без перезарядки, как раньше.

## Особенности (что реально делает игра)

| Особенность | Стволы | Действие |
|---|---|---|
| Урон по машинам | Кобра +50 %, Пчела и Таран +30 %, Молот +30 %, Полярник ×2, Бетон ×2,5 | урон пули по машинам преследователей |
| Прошивает насквозь | Бульдог, Ворон, Молот, Полярник, Бетон | пуля летит дальше после попадания; на следующей цели урон −30 % |
| Отбрасывает врага | Мясник, Таран | попадание отталкивает противника (кроме босса) |
| Отдача меньше сбивает прицел | Тень (не сбивает), Сокол-К (почти не сбивает), Вихрь (вдвое меньше) | |
| Взрыв радиусом 6 м | Шлагбаум | урон всем рядом с местом попадания |

Тексты особенностей из присланного каталога заменены на те, что совпадают с действием в игре. Пример: «Бесконечные патроны» у «Шмеля» противоречили ограниченным патронам, поэтому особенность заменена.

## Модели

- Модели оружия: набор Flat Guns East/West (CC0), см. `assets/arsenal/CREDITS.md`. Сжаты meshopt, всего ≈0,6 МБ.
- Модель загружается, только когда ствол берут в руки.
- «Шлагбаума» в наборе нет: это простая процедурная модель.
- Картинки для магазина: `assets/arsenal/img/*.webp`, 600×280.
