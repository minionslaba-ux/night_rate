# Площадки: сайт, Telegram, ВКонтакте, MAX

Один аккаунт на всех площадках. Вход через площадку проверяет сервер (Supabase, функция `nf-login`): Telegram, ВК и MAX подписывают данные запуска, сервер сверяет подпись и выдаёт сессию игрока. Пароли в мини-приложениях не нужны.

## Как игра понимает, где она открыта

| Площадка | Признак в адресе | Что меняется |
| --- | --- | --- |
| Сайт | — | плашка «Установить игру», регистрация по логину и паролю |
| Telegram | `#tgWebAppData=…` | вход сам, без форм; мост Telegram (ready, expand) |
| ВКонтакте | `?vk_app_id=…&sign=…` | вход сам, без форм логина и пароля; значок 12+; звук на паузе, когда приложение свёрнуто |
| MAX | `#WebAppData=…` или `?src=max` | вход сам, без форм; мост MAX |

Во всех случаях игра ставится на паузу и выключает звук, когда вкладку или приложение свернули.

## Один аккаунт везде: коды

- **Получить код:** «Профиль» → «Получить код для другого устройства». Код из 8 знаков действует 10 минут.
- **Ввести код на сайте:** вход в тот же аккаунт.
- **Ввести код в Telegram, ВК или MAX:** эта площадка навсегда привязывается к аккаунту кода.

Там же есть кнопка «Удалить аккаунт», она нужна по правилам VK Mini Apps. Тестовый профиль из игры не удаляется.

## Вход через Telegram на сайте

На сайте под регистрацией есть кнопка «Войти через Telegram». Игра открывает страницу Telegram, игрок подтверждает вход, Telegram возвращает его в игру с подписанными данными. Сервер (`nf-login`) проверяет подпись токеном бота и выдаёт сессию. Пароль не нужен. Аккаунт тот же, что в Telegram Mini App.

## Вход через ВКонтакте на сайте (VK ID)

На сайте под кнопкой Telegram есть «Войти через ВКонтакте» (приложение VK ID **54878563**, домен nightfaregame.com, Redirect URL `https://nightfaregame.com/`). ВК открывает своё окно, игрок подтверждает вход, браузер получает токен VK ID. Сервер (`nf-login`) сам спрашивает у ВК, чей это токен (`id.vk.com/oauth2/user_info`), и только тогда входит. Секрет для этого не нужен. Аккаунт тот же, что в мини-приложении ВК (vk.com/app54878467).

## Привязка способов входа (один профиль)

- **На сайте:** «Профиль» → «Способы входа». Там видно, что привязано (Telegram, ВКонтакте, MAX), и есть кнопки «Привязать». Игрок подтверждает вход в Telegram или ВК, и этот способ начинает вести в его текущий профиль.
- **Если этот Telegram или ВК уже входил в другой профиль:** пустой профиль (без прогресса) удаляется автоматически. Если в нём есть прогресс, привязка отклоняется, чтобы ничего не потерять: такие случаи объединяем вручную.
- **MAX** входа для сайта не имеет. На сайте или в Telegram нужно получить код («Получить код для другого устройства») и ввести его в игре внутри MAX («Привязать по коду»). Так же можно привязать мини-приложения Telegram и ВК.

## Что сделать владельцу (по шагам)

Секреты добавляешь только ты сам, в чат их не присылай.
Supabase → проект **night-fare** → Edge Functions → Secrets → Add new secret.

1. **Telegram.** Бот игры: **@night_fare_bot** (создан). В @BotFather отправь `/newbot`, затем `/newapp` и укажи адрес игры. Токен бота сохрани как секрет `TELEGRAM_BOT_TOKEN`.
   Чтобы работала кнопка «Войти через Telegram» на сайте, в @BotFather отправь `/setdomain`, выбери этого бота и укажи `nightfaregame.com` (раньше был `minionslaba-ux.github.io`). Один бот обслуживает и мини-приложение, и вход на сайте, и это один и тот же аккаунт игрока.
2. **ВКонтакте.** Мини-приложение создано: **ID 54878467** (vk.com/app54878467), адрес игры `https://nightfaregame.com/`. Картинки — папка `promo/` (vk-icon-576.png, vk-cover-1120x630.jpg, vk-snippet-537x240.jpg). Скопируй «Защищённый ключ» из настроек и сохрани как секрет `VK_APP_SECRET`.
3. **MAX.** Бот игры: **@se14877440_1_bot** (создан, секрет `MAX_BOT_TOKEN` добавлен). Адрес мини-приложения: `https://nightfaregame.com/?src=max`.

Пока секрета нет, вход на этой площадке отвечает «ещё не настроен», и игра работает в режиме гостя.

## Ошибки игроков

Ошибки скриптов вместе с версией игры, площадкой и браузером попадают в таблицу `client_errors`. Посмотреть их: Supabase → Table Editor → `client_errors`.
Игра проверяется на совместимость со старыми браузерами (ES2018: Chrome 64, Safari 12; это старые WebView на Honor и Huawei) при каждой сборке.
