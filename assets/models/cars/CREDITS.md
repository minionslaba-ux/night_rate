# Машины гаража

Модели из присланного пакета магазина (в README пакета указано: CC0, grab3d.com). Файлы:
`taxi`, `taxi90` (1990s-taxi), `hatch` (rally-car), `sedan` (muscle-car), `wagon` (1980s-station-wagon), `van` (mail-truck).
Патрульная машина полиции — `assets/models/police.glb`.

Что изменено для игры:
- текстуры уменьшены до 1024 px, геометрия сжата meshopt (≈0,4 МБ на машину);
- в текстуре кузова цвет основной окраски заменён светло-серым, чтобы краска из гаража ложилась поверх;
- «Универсал «Дача»» — та же модель, что «Семейный», в белой краске;
- бронеплиты «Броневана» добавляются в игре.

Картинки для гаража — `assets/shop/img/car-*.webp` (рендеры из пакета, уменьшены).

# Контейнер

`assets/models/container.glb` — присланная модель морского контейнера. Синяя краска в текстуре заменена серой, чтобы каждый контейнер окрашивался своим цветом. Текстуры уменьшены, геометрия сжата meshopt (≈0,38 МБ). Модель стоит на компьютерах; на телефонах контейнеры остаются цветными коробками.
