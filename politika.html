Политика обработки персональных данных

в онлайн-игре «Ночной тариф»

Редакция от 5 ноября 2026 года. Размещена по адресу https://nightfaregame.com/politika.html.

1. Общие положения

  1. 1.1. Политика составлена в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных» и определяет, какие персональные данные пользователей игры «Ночной тариф» (сайт nightfaregame.com, мини-приложения в Telegram, ВКонтакте и MAX, бот @night_fare_bot; далее — «Игра») обрабатываются, с какой целью и как.
  2. 1.2. Оператор персональных данных — Моисеенко Константин Иванович, ИНН 470313493504 (далее — «Оператор»).
  3. 1.3. Играть можно только с профилем. Профиль создаётся при входе через Telegram, ВКонтакте или MAX. Входя в Игру, пользователь даёт согласие на обработку своих персональных данных на условиях этой Политики.

2. Какие данные обрабатываются

  1. 2.1. Данные из Telegram, ВКонтакте и MAX при входе: идентификатор пользователя в мессенджере, имя и фамилия, имя пользователя (username) в Telegram. Пароли и номера телефонов Игра не получает.
  2. 2.2. Данные, которые пользователь создаёт сам: имя в Игре, сообщения в чате Открытого города, жалобы на сообщения и голосовую связь.
  3. 2.3. Игровые данные: прогресс в эпизодах, монеты, машины, достижения, статистика (поездки, выполненные задания), время последнего входа.
  4. 2.4. Технические данные: версия Игры, тип устройства и браузера, тексты технических ошибок — для их исправления.
  5. 2.5. Данные Telegram-бота: если пользователь нажал «Старт» в боте @night_fare_bot — его идентификатор, имя и username, чтобы бот мог присылать новости игры.
  6. 2.6. Голосовая связь в группе: звук передаётся напрямую между устройствами участников группы (технология WebRTC) и не записывается и не хранится Оператором. Для установки связи устройства обмениваются сетевыми адресами (IP) друг с другом и с сервером Google STUN.

3. Цели обработки

  1. 3.1. Вход в Игру и сохранение прогресса на разных устройствах и площадках (один профиль для сайта, Telegram, ВКонтакте и MAX).
  2. 3.2. Работа игровых функций: Открытый город, чат, группы с друзьями и голосовая связь, задания, достижения.
  3. 3.3. Модерация: рассмотрение жалоб, скрытие сообщений, ограничение чата и голосовой связи за нарушения Правил игры.
  4. 3.4. Исправление ошибок и обобщённая статистика для улучшения Игры (без раскрытия данных конкретных пользователей третьим лицам).

5. Как обрабатываются и хранятся данные

  1. 5.1. Оператор обрабатывает данные с использованием средств автоматизации: сбор, запись, систематизация, накопление, хранение, уточнение, использование, удаление.
  2. 5.2. Для работы Игры используются сервисы третьих лиц: облачная база данных Supabase, хостинг сайта GitHub Pages, сети доставки файлов (jsDelivr, unpkg) для загрузки библиотек Игры, Telegram, VK ID и мини-приложения ВКонтакте, мессенджер MAX. Им передаются только данные, необходимые для их работы.
  3. 5.3. Пуш-напоминания. Если пользователь сам нажал «Напоминать мне играть» и разрешил уведомления в браузере, Оператор хранит адрес подписки браузера и краткое состояние игры (имя водителя, машина, уровень бензина и чистоты, число пройденных глав, время последней игры), чтобы присылать 1–3 напоминания в день. Выключить можно в профиле Игры или в настройках браузера; подписка тогда удаляется.
  4. 5.4. Реклама. На сайте nightfaregame.com на телефонах между главами сюжета может показываться полноэкранная реклама Рекламной сети Яндекса (ООО «Яндекс»), не чаще раза в 5 минут. Для этого подключается код Яндекса, который может использовать файлы cookie и данные об устройстве по правилам Яндекса (yandex.ru/legal/confidential). Оператор не передаёт Яндексу данные профиля пользователя. В мини-приложениях Telegram, ВКонтакте и MAX эта реклама не показывается.
  5. 5.5. Часть данных (настройки, звук, время года, недавние состояния игры) хранится в браузере пользователя (localStorage).
  6. 5.6. Оператор принимает организационные и технические меры для защиты данных: доступ к базе данных ограничен, вход проверяется подписью мессенджера на сервере, обмен данными идёт по защищённому протоколу HTTPS.
  7. 5.7. Данные хранятся, пока у пользователя есть профиль, либо до отзыва согласия. Технические журналы ошибок хранятся не дольше, чем нужно для исправления ошибок.
